# portfolio-pages

Public GitHub Pages deployment for qiyuanhuakai's technical portfolio.

```text
index.html
content.js
style.css
motion.js
.nojekyll
```

- `index.html`: static rendering shell
- `content.js`: portfolio copy and project data
- `style.css`: visual system and responsive motion styles
- `motion.js`: project filters/search, evidence dialog, sharing and reading preferences
- `.nojekyll`: disables Jekyll processing
- GitHub's built-in repository archive provides the downloadable ZIP
- `README-OFFLINE.txt`: instructions for browsing the downloaded site

Live site: https://qiyuanhuakai.github.io/portfolio-pages/

Sakura Circuit uses soft pink, muted plum and lavender with abstract petal and circuit lines. It includes responsive layouts, light/dark/system themes, a static reading option, project anchors, a source index and print styles. No external fonts, runtime packages or backend are required.

The canonical editable source is kept in the private `qiyuanhuakai/portfolio` repository. Manual content edits should be made there first and then synchronized here.
