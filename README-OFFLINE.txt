qiyuanhuakai · Portfolio

离线浏览：
1. 下载仓库 ZIP 或公开发布仓库 ZIP。
2. 解压全部文件。
3. 双击 index.html。
4. 页面本体没有外部字体、CDN、API 或后端依赖；项目证据链接仅在联网时跳转 GitHub。

功能：
- 可按方向筛选，或搜索项目名、问题与技术栈。
- 点击“查看证据”阅读各项目的来源索引，按 Escape 关闭。
- 顶部“阅读偏好”可选择浅色、深色或跟随系统，并开启静态阅读。
- 复制项目链接会使用公开站点地址；复制受限时可从弹窗手动复制。
- 页脚“打印 / 存为 PDF”会包含全部项目，不受当前筛选影响。
- 阅读偏好在允许本地存储时会保存；下载和外部来源需联网。
